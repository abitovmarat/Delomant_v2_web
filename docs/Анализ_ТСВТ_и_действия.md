## 1. Что такое ТСВТ (кратко)

Онлайн-сервис визуальной аналитики таможенной статистики ФТС РФ (импорт/экспорт)
на технологиях BIG DATA. Ежемесячное обновление, экспорт в Excel, работа 24/7 в
облаке. Есть демо с ограниченными данными и один CTA — «Отправить заявку на
подключение». Цен на странице нет.

## 3. Наши преимущества, которых у ТСВТ нет (позиционирование)

На этом строим отличие — НЕ воюем на их поле (глубина базы ФТС РФ), а давим на
широту и готовый результат:

1. **Свои выгрузки пользователя** — не только готовая витрина, а загрузка
   собственных Excel/CSV.
2. **Контрагентский уровень** — отправители / получатели / изготовители,
   диаграммы связей «компания → компания». У ФТС-данных ТСВТ этого обычно нет.
3. **Зарубежная таможня** — Колумбия, Перу, Казахстан, Кыргызстан. У них только РФ.
4. **UN Comtrade** — международная зеркальная статистика.
5. **Готовые презентации** — экспорт в PPTX / PDF / HTML. У них финал — Excel.

**Главная формула первого экрана:**
> Не просто база таможни РФ — ваши данные + мир + контрагенты + готовая
> презентация в один клик.

## 4. Что честно учесть (их сила)

- ТСВТ силён глубиной по РФ через единую официальную базу ФТС (полная версия
  2018–2021, ежемесячно). У нас данные РФ — из пользовательских выгрузок.
- Вывод: в лоб по «объёму базы РФ» не сравниваемся, уводим разговор на широту
  источников и на готовый отчёт.

## 6. Идеи «6 преимуществ Delomant» (черновик плиток)

1. **Ваши данные + витрины** — анализ собственных выгрузок, а не только готовой базы
2. **Контрагенты** — отправители, получатели, изготовители и связи между ними
3. **Мир, а не только РФ** — UN Comtrade + зарубежная таможня (Колумбия, Перу, КЗ, КГ)
4. **От данных до отчёта** — готовая презентация в PPTX / PDF / HTML
5. **Без установки** — работает в браузере, доступ по авторизации
6. **Быстро** — от выгрузки до графиков и экспорта за минуты
