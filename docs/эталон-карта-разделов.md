# Карта разделов эталонного отчёта Delomant

Чертёж для модуля «Презентация/Отчёт». Составлен по двум эталонам из `обучение/`:
**`Лимонная.docx`** (18 нативных Word-графиков, 30 таблиц) и **`Крахмал.docx`** (5 графиков, 32 таблицы).
Шаблон у обоих один — меняется только состав глав под конкретный рынок.

**Легенда источника данных:**
- 🟢 **Авто** — считается приложением из таможенной выгрузки (вкладка «Анализ»).
- 🟡 **Заготовка** — данных в таможенной выгрузке нет; пользователь вставляет вручную (позже — «найти» из внешнего источника).
- ⚪ **Шаблон** — boilerplate/автосборка (обложка, списки, «О нас», введение).

---

## 1. Общий каркас (фиксированный порядок)

```
Обложка
 └ Список таблиц         (автосборка из нумерованных таблиц)
 └ Список рисунков        (автосборка из нумерованных графиков)
О НАС                     (фикс-текст бренда)
ВВЕДЕНИЕ                  (7 таблиц-методология)
ГЛАВА 1..N                (состав под рынок — см. ниже)
ПРОГНОЗ / ФАКТОРЫ
```

**Стили-заголовки Word (для распознавания/воспроизведения):**

| Стиль | Роль |
|---|---|
| `Delomant1` | ГЛАВА (H1) |
| `Delomant2`, `Delomant3` | Раздел / подраздел (1.1, 3.1.1) |
| `Delomant4` | Подпись графика — «Рисунок N. …» |
| `Delomant8` | Подпись таблицы — «Таблица N. …» |
| `Delomant6`, `Delomantb` | «Источник: …» (под графиком/таблицей) |
| `Delomant2` | Карточка компании (досье) |
| `Delomant` | Основной текст |
| `af8` / `12` | Заголовок и строки списков таблиц/рисунков |

**Инварианты стиля:** каждый график и таблица — пронумерованы («Рисунок N» / «Таблица N»), подпись сверху, «Источник» снизу. Нарратив везде через CAGR: *«вырос с X (2022) до Y (2025), +Z %, CAGR W %»*. Графики — нативные Word-чарты (редактируемые), не картинки.

## 2. Реестр типов блоков

### 2.1 Boilerplate ⚪

| Блок | Что показывает | В приложении |
|---|---|---|
| Обложка | Лого + узор + «АНАЛИЗ РЫНКА … В РОССИИ» + месяц/год | ✅ `title` |
| Список таблиц | Автонумерованный список всех таблиц + стр. | ❌ добавить (автосборка) |
| Список рисунков | Автонумерованный список всех графиков + стр. | ❌ добавить (автосборка) |
| О НАС | Фикс-текст о Delomant Group | ✅ `text`/`intro` |
| Введение (7 таблиц) | Объект · Цель · Задачи · География · Хронология · Методы и источники · Замечания о методологии | ⚠️ частично (`intro`) — добавить шаблон 7 таблиц |

### 2.2 Обзор рынка / потребление / производство 🟡 (Росстат, отраслевые данные)

| Блок | Что показывает | В приложении |
|---|---|---|
| Целевые отрасли применения | Таблица «отрасль → применение» | 🟡 заготовка (таблица) |

| Динамика производства секторов-потребителей | Таблица по годам + CAGR (Росстат) | 🟡 заготовка (таблица+CAGR) |
| Объём и динамика рынка / баланс | Таблица баланса рынка (произв.+импорт−экспорт) | 🟡 заготовка (частично считается из таможни: импорт/экспорт) |

### 2.3 Внешняя торговля 🟢 (таможенная выгрузка — ядро приложения)

| Блок | Что показывает | В приложении |
|---|---|---|
| Пошлины ТН ВЭД | Справочная таблица импортная/экспортная пошлина | 🟡 справочник (ТН ВЭД) — полу-ручное |
| Экспорт: объём и динамика | 3-панель стоимость/натур + CAGR по годам | ✅ `volumes` |
| Экспорт: по странам назначения | Структура % (натур/стоим) | ✅ `countries` |
| Импорт: объём и динамика | 3-панель + CAGR | ✅ `volumes` |

| Цены: динамика по назначению | Линии руб./кг по назначению | ⚠️ нет (нужна классификация назначения) |

## 3. Что уже умеет приложение vs что добавить

**🟢 Готово (ядро «внешней торговли»):** объёмы+CAGR, по странам (экспорт/импорт), цены по странам, ТОП поставщиков/получателей, Sankey (отпр→пол, изг→пол), сегмент получателя, регион по ИНН.

**❗ Пробелы для полного эталона:**
1. **Сезонность импорта по месяцам** (100 % = год) — новый тип графика.
2. **Тип слайда «по регионам РФ»** — обогатитель есть, слайда нет.
3. **Классификация формы и назначения товара** (моногидрат/ангидрид; пищевое/фарма/косметика/…) → таблицы и цены в этих разрезах.
4. **Список таблиц / список рисунков** — автосборка нумерации.
5. **Введение — шаблон 7 таблиц-методологии.**

**🟡 Заготовки (данных в таможне нет):**
1. **Обзор рынка** — отрасли применения, категории продуктов, динамика производства секторов (Росстат), баланс рынка, структура потребления.
2. **Досье компаний** — финансы/руководитель/описание по ИНН (ФНС/Dadata).
3. **Факторы и прогноз** — драйверы, барьеры, локализация, прогноз до 2030.

## 4. Механика заготовки (v1 — только ручное заполнение)

Слайд/блок-заготовка вместо тупика «Нет данных»:
- **Скелет** будущего графика/таблицы (бледный контур — видно, каким станет).
- **Плашка** «Не хватает: <что именно>» + короткое пояснение.
- Кнопка **«Заполнить вручную»** → редактор недостающих данных (для сегмента — существующий словарь на вкладке «Обогащение»; для обзора рынка/досье/прогноза — соответствующий мини-редактор таблицы).
- В экспортированном деке кнопка не рисуется — заготовка остаётся чистой.
- Позже — кнопка **«Найти автоматически»** (Росстат для обзора, Dadata для досье).

Опора в коде: реестр обогатителей `ENRICHERS` (`adds: [колонки]`) — заготовка знает недостающую колонку → находит обогатитель/редактор.

## 5. Открытые вопросы к обсуждению

- Полный длинный **отчёт** (Word/HTML, как эталон) — отдельный формат рядом со слайдами, или слайды остаются единственным выходом, а заготовки просто расширяют их набор?
- Порядок и обязательность глав — фиксировать по эталону или собирать мастером под каждый рынок (как сейчас «Собрать отчёт»)?
- Классификация формы/назначения — по описанию товара (гр. 31) правилами, как сегмент, или отдельным словарём?
