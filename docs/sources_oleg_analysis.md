## 1. Колумбия (DIAN)

- Размерность: `A1:DH417415`, 112 колонок, один лист. Внутри xlsx: `sheet1.xml` = 1.47 ГБ,
  `sharedStrings.xml` = 116 МБ → **грузить только потоково** (SAX/стриминг), не SheetJS в память.
- Заголовки — испанские имена полей (строка 1).

### Ключевые поля (индекс → имя)
- Декларация: `NUMERO_DE_FORMULARIO`(A), `TIPODECLARACION`(P), `FECHA_ACEPTACION_DECLARACION`(DB).
- Импортёр: `NIT_IMPORTADOR`(B), `RAZON_SOCIAL_IMPORTADOR`(C), `DIRECCION`(E), `CIUDAD`(AD), `TELEFONO`(F).
- Декларант/агент: `NIT_DECLARANTE`(I), `RAZON_SOCIAL_DEL_DECLARANTE`(K).
- Иностранный поставщик: `CODIGO_PAIS_EXPORTADOR`(AE), `DIRECCIÓN_EXPORTADOR`(AF),
  `E_MAIL_PROVEEDOR`(AG). ⚠️ **Явного названия экспортёра (RAZON_SOCIAL) в файле нет** — только
  страна+адрес+e-mail. Проверить, нет ли названия в адресном поле.
- Товар: `SUBPARTIDA_ARANCELARIA`(AO) = **HS10**, `DESCRIPCION_MERCANCIA`(BU), `LINEA_DESCRIPCION`(BT).
- Страны: `CODIGO_PAIS_PROCEDENCIA`(AJ), `CODIGO_PAIS_ORIGEN`(AV), `CODIGO_PAIS_COMPRA`(AZ).
- Количество/вес: `CANTIDAD_DCMS`(BG), `CODIGO_UNIDAD_FISICA`(BF), `PESO_NETO_KGS`(BB), `PESO_BRUTO_KGS`(BA), `NUMERO_DE_BULTOS`(BD).
- Стоимость: `VALOR_FOB_USD`(BH), `VALOR_FLETES_USD`(BI), `VALOR_SEGUROS_USD`(BJ),
  `VALOR_OTROS_GASTOS_USD`(BK), `VALOR_ADUANA_USD`(BM = CIF), `TASA_DE_CAMBIO`(AN).
- Платежи: `ARANCEL`(BV, пошлина %), `IVA`(CA, НДС %), `SALVAGUARDIA`, `DERECHOS_COMPENSATORIOS`,
  `TOT_LIQUID_DERECHO_ANTIDUMPING` (антидемпинг) и суммы к оплате.
- Счёт: `NUMERO_DE_FACTURA`(AH), `FECHA_FACTURA`(AI).
- Транспорт: `CODIGO_MODO_TRANSPORTE`(AK), `DOCUMENTO_DE_TRANSPORTE`(AB), `MANIFIESTO_DE_CARGA`(Z).

### Склейка описания (250 символов)
Подтверждено на примере декларации `12026000029243`: две строки различаются **только**
по `LINEA_DESCRIPCION` (1, 2) и `DESCRIPCION_MERCANCIA` (продолжение текста). Остальные
110 полей идентичны.
- **Правило:** сгруппировать по декларации + товарной строке, отсортировать по
  `LINEA_DESCRIPCION`, склеить `DESCRIPCION_MERCANCIA` встык.
- ⚠️ **Открытый вопрос:** как отделять товарные строки внутри декларации, когда в одной
  декларации несколько разных HS (`SUBPARTIDAS`(BE) = число субпозиций). Нужен пример
  многотоварной декларации, чтобы определить истинный ключ строки (вероятно
  `NUMERO_DE_FORMULARIO` + `SUBPARTIDA_ARANCELARIA` + порядок). Проверить перед парсингом.

### Прочее
- Даты смешанные: часть — Excel-serial (`46197`), часть — строки `MM/DD/YYYY`. Нормализовать.
- Деньги — целые (похоже, округлены до целого USD/песо).
- Кодировка: у части строковых значений побиты символы (напр. `AN╙NIMA`, `IMPORTACI¿N`) —
  это потеря на стороне DIAN (í/ó/é→`¿`), восстановить нельзя.

### ✅ РЕАЛИЗОВАНО (2026-08-06): `scripts/parse_colombia_dian.py`
Потоковый офлайн-парсер написан и **проверен на файле июнь-2026**:
- Правило склейки подтверждено валидацией: в файле **1 декларация = 1 HS10**, случаев
  пере-склейки (HS сменился без сброса LINEA) — **0**. Новая позиция при `LINEA=="1"`.
- Фильтр юрлиц: оставляем NIT, начинающийся на **8/9** (колумбийские юрлица).
- Результаты прогона: 417 415 строк → 39 438 позиций → **39 055 юрлиц оставлено**,
  383 физлица (0.97%) отброшено. Импортёров 4 026; пар импортёр×HS6 — 21 817.
  Итоги периода: нетто ~614.7 тыс. т, CIF ~$954.6 млн, FOB ~$947.8 млн. Время ~80 с.
- Осмысленность подтверждена: топ — ECOPETROL (нефть 271012, $82.8M), Avianca (880240),
  ESENTTIA (полимеры) и т.п.
- Выход: `co_import_normalized.jsonl` (по позициям) + `co_import_aggregate.json`
  (импортёр×HS6, компактный, app-ready). Даты → ISO. HS10→HS6.
- Осталось: перевод описаний исп.→рус.; словарь кодов стран/транспорта; интеграция
  агрегата в модель приложения (`dataSource: foreign_customs`).

## 3. Казахстан (stat.gov.kz)

Публикация-книга. Листы: Обложка, Метаданные, Содержание, Метод.пояснения,
**«4 знака ТН ВЭД», «6 знаков ТН ВЭД», «10 знаков ТН ВЭД»**.
- Данные — взаимная торговля РК со странами ЕАЭС, январь-май 2026.
- Шапка **многоярусная** (3–4 строки): месяц × (экспорт/импорт) × (тонн / доп.ед. / тыс. USD).
- Иерархия строк: строка товара (код + «Всего»), ниже строки стран с **пустым кодом** →
  нужен forward-fill кода/наименования.
- Единицы: тонны и тыс. USD (лист метаданных фиксирует методику и источник — полезно для провенанса).
- Извлечение = де-пивот в длинный формат: `код, товар, страна, период, поток, тонны, USD`.

## Единая целевая схема (черновик)

Свести Колумбию/Перу к «контрагентским» записям, Казахстан/Кыргызстан — к «агрегатным».

**Контрагентская запись (Колумбия, Перу):**
`country_src, decl_no, date, hs10, hs6, goods_desc, importer_id, importer_name,
origin_country, dispatch_country, qty, unit, net_kg, gross_kg, fob_usd, freight_usd,
insurance_usd, cif_usd, transport_mode, customs, invoice_no` (+ для Колумбии: пошлины/НДС/агент/поставщик).

**Агрегатная запись (Казахстан, Кыргызстан):**
`country_src, period, hs_code, hs_level, product_name, partner_country, flow, weight_t, value_usd`.

Оба типа ложатся на текущую модель приложения (`main.js`: `dataSource` = file/comtrade →
добавить `foreign_customs` / `foreign_stat`). HS6 из обоих типов сшивается с
`data/commodity_faostat_map.json`.

## Автоматизация получения (разведка 2026-08-06)

Вывод: **живого API-«запроса», как у Comtrade, нет ни у одного** — все четыре отдают
периодические файлы. Правильная схема — офлайн-робот по расписанию (скачал → распарсил →
компактный JSON), т.е. «Вариант B» как у `fetch_comtrade_countries.js`.

- **Колумбия (DIAN).** ✅ Прямые скачиваемые ZIP со стабильным URL-шаблоном:
  `https://www.dian.gov.co/dian/cifras/Documents/Registro-declaraciones-de-importacion-y-exportacion/Importaciones-<месяц>-<даты>-<год>.zip`
  (и `Exportaciones-*.zip`), публикуются понедельно. Робот: спарсить список ссылок со
  страницы реестра → скачать новые → распаковать → потоковый парсинг → JSON.
  Внимание: datos.gov.co/DANE — это агрегаты (набор `2eyg-yu5f` «non-tabular», без компаний);
  контрагентский уровень только через bulk-файлы DIAN.
- **Перу (SUNAT).** 🟡 Портал datosabiertos.gob.pe — это **DKAN (Drupal)**, а не классический
  CKAN: путь `/api/3/action/...` отдаёт HTML. Нужен точный адрес ресурса (файла) на портале —
  докрутить. Забор — скачивание файла набора.
- **Казахстан.** 🟡 `stat.gov.kz/.../foreign-market/spreadsheets/` + `data.egov.kz` (XML/JSON/Excel)
  + Taldau. Забор — скачивание Excel-публикации или egov-API; формат-«простыня».
- **Кыргызстан.** 🟡 `stat.gov.kg` — файлы публикаций (Excel/PDF). Забор — скачивание файла.

Отличия от прокси Comtrade: (1) не в реальном времени — обновление раз в неделю/месяц;
(2) разбор тяжёлых файлов (Колумбия) делать офлайн у себя, на cloud4box класть готовый JSON;
(3) состав полей в публичном источнике сверить с присланными файлами перед написанием парсера.
