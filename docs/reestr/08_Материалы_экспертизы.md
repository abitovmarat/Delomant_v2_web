## Скриншоты основных разделов
Приложить снимки экрана по разделам (рекомендуемый список):
- ⬜ Форма входа
- ⬜ Данные — загрузка Excel и выбор UN Comtrade
- ⬜ Обработка данных
- ⬜ Анализ (несколько представлений)
- ⬜ Обогащение
- ⬜ Презентация / экспортированный отчёт
- ⬜ Зарубежная таможня (переключатель стран, таблица, поиск, разворот импортёра)
- ⬜ О программе (виден номер версии)

> Скриншоты можно снять с демо-стенда; сложить в `docs/reestr/screenshots/`.
