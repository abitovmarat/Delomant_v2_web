# Материалы для проведения экспертизы

## Демонстрационный стенд
- URL демо-/экспертной версии: https://delomant-analytics-system.ru/
- Учётные данные для входа (тестовая учётка): ⚠️ ЗАПОЛНИТЬ (логин/пароль).
- Срок доступности стенда на период экспертизы: ⚠️ ЗАПОЛНИТЬ.

## Скриншоты основных разделов
Приложить снимки экрана по разделам (рекомендуемый список):
- ⬜ Форма входа
- ⬜ Данные — загрузка Excel и выбор UN Comtrade
- ⬜ Обработка данных
- ⬜ Анализ (несколько представлений)
- ⬜ Обогащение
- ⬜ Презентация / экспортированный отчёт
- ⬜ О программе (виден номер версии)

> Скриншоты можно снять с демо-стенда; сложить в `docs/reestr/screenshots/`.

Не включать в комплект экраны, таблицы и диаграммы по получателям,
отправителям, изготовителям, ИНН, сегментам и холдингам: контрагентский слой не
входит в заявляемую версию 0.9.

## Видео-демонстрация (желательно)
⬜ Короткая запись сквозного сценария: вход → получение открытых данных →
анализ → формирование отчёта. Приложить файл или ссылку. Контрагентские функции
в сценарии не показывать.
