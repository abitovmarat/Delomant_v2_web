# Описание программного обеспечения

## Наименование и назначение

**Delomant — Аналитика ВЭД** — веб-приложение для анализа данных
внешнеэкономической деятельности. Программа предназначена для аналитиков,
специалистов по ВЭД и логистике: загрузка выгрузок таможенных/торговых данных,
их обработка и очистка, аналитика по контрагентам, странам и товарам,
обогащение справочниками, работа с открытыми зарубежными таможенными данными и
подготовка презентаций-отчётов.

Программа работает как одностраничное веб-приложение (SPA) в браузере, доступ
закрыт авторизацией. Установка на компьютер пользователя не требуется.

## Функциональные возможности

Приложение построено из семи функциональных модулей (левое меню):

### 1. Данные
Загрузка пользовательских выгрузок в форматах Excel (`.xlsx`, `.xls`) и
альтернативная загрузка зеркальной статистики **UN Comtrade** по странам, кодам
ТН ВЭД и периодам (через встроенный прокси). Определение источника данных влияет
на доступный набор анализов.

### 2. Обработка данных
Очистка и нормализация загруженной таблицы: работа с заголовками, приведение
столбцов, подготовка данных к анализу. Результат — обработанный набор, на котором
строятся аналитические представления.

### 3. Анализ
Аналитические представления по обработанным данным: разрезы по товарам, странам,
контрагентам (отправители, получатели, изготовители), динамике и стоимости.
Часть анализов, требующих контрагентского уровня, недоступна на агрегированной
статистике UN Comtrade — программа явно объясняет причину вместо пустого графика.

### 4. Обогащение данных
Дополнение записей из встроенных справочников (например, справочник компаний
`company_dictionary.json`) и пересчёт стоимостных показателей по курсам ЦБ РФ
(`cbr_rates.json`). Планируется расширение источников обогащения.

### 5. Презентация
Формирование презентаций-отчётов в фирменном стиле на основе результатов анализа,
включая экспорт самодостаточного HTML-дека. Отчёты по зеркальной статистике
сопровождаются обязательной подписью об источнике данных.

### 6. Зарубежная таможня
Витрина открытых зарубежных таможенных данных по импорту (Колумбия — DIAN,
Перу — SUNAT): поиск по импортёру, коду ТН ВЭД (HS6) и названию товара,
сортировка, разворот импортёра по товарным кодам, экспорт в Excel. Показатели —
объёмы (нетто), стоимость (CIF/FOB), число позиций в разрезе «импортёр × товар».
Названия товаров приводятся на русском по коду ТН ВЭД. Отображаются только
импортёры-юридические лица; данные снабжаются пометкой об источнике и его статусе
(например, данные DIAN — неофициальные, без статистической валидации).

## Отличительные особенности

- Работа как с собственными выгрузками пользователя, так и с открытой
  международной статистикой (UN Comtrade) через безопасный серверный прокси
  с белым списком параметров.
- Слой открытых зарубежных таможенных данных (Колумбия, Перу) с приведением
  названий товаров на русский по коду ТН ВЭД и фильтрацией персональных данных
  (отображаются только юридические лица).
- Разграничение анализа по типу источника данных.
- Доступ к приложению и всей его статике только после авторизации.
- Не требует установки на рабочее место — работает в браузере.
