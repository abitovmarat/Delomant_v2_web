# Документы по эксплуатации

## Требования к программному и аппаратному обеспечению {#требования}

### Рабочее место пользователя
- Современный браузер (Chrome, Yandex Browser, Firefox, Edge — актуальные версии).
- Разрешение экрана от 1280×800.
- Доступ в интернет.
- Установка ПО на рабочее место не требуется.

### Сервер (площадка размещения)
- ОС: Linux (типовой веб-хостинг).
- Веб-сервер: Apache (`.htaccess`) за nginx.
- PHP 8+ с поддержкой сессий.
- HTTPS-сертификат.
- Исходящий доступ в интернет (для прокси к UN Comtrade).
- Дисковое пространство: минимальное (приложение — статика + несколько PHP-файлов
  и JSON-справочники); ⚠️ ЗАПОЛНИТЬ фактические значения (ОЗУ/CPU тарифа хостинга).

## Порядок обновления ПО {#обновление}

Обновление выполняется правообладателем централизованно на стороне сервера;
действий со стороны пользователей не требуется.

1. Внести изменения в исходный код.
2. Собрать новый дистрибутив: `node build.mjs`.
3. Выложить содержимое `dist/` на хостинг (замена файлов).
4. Файл `config.php` (пароль) при обновлении **не затрагивается**.
5. Обновление версии отражается в разделе «О программе».

Обновление справочных данных — перегенерация JSON офлайн-скриптами и
перевыкладка (см. [04_Установка_и_развертывание.md](04_Установка_и_развертывание.md)).

Обновление данных модуля «Зарубежная таможня» выполняется офлайн правообладателем:
свежие открытые выгрузки источников (DIAN, SUNAT, stat.gov.kz, stat.gov.kg)
обрабатываются препроцессорами на Python (`scripts/parse_*.py`,
`scripts/prep_foreign_data.py`), результат (`data/foreign/*.json`) перевыкладывается
на сервер. Рабочий сервер и пользователи в этом не участвуют.

> ⚠️ ЗАПОЛНИТЬ: политика версионирования (semver/дата), периодичность обновлений,
> канал уведомления пользователей об обновлениях.
