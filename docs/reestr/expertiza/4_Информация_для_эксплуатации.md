# Документация, содержащая информацию, необходимую для эксплуатации экземпляра программного обеспечения, предоставленного для проведения экспертной проверки

**Программное обеспечение:** «Delomant — Аналитика ВЭД»
**Экспертный стенд:** https://delomant-analytics-system.ru/
**Учётные данные:** ⚠️ ЗАПОЛНИТЬ (логин/пароль тестовой учётной записи)

## 1. Требования к программному и аппаратному обеспечению

### 1.1. Рабочее место пользователя
- Современный браузер (Chrome, Yandex Browser, Firefox, Edge — актуальные версии).
- Разрешение экрана от 1280×800.
- Доступ в интернет.
- Установка ПО на рабочее место **не требуется**.

### 1.2. Сервер (площадка размещения)
- ОС: Linux (типовой веб-хостинг).
- Веб-сервер: Apache (`.htaccess`) за nginx.
- PHP 8+ с поддержкой файловых сессий.
- HTTPS-сертификат (обязательно).
- Исходящий доступ в интернет (для прокси к UN Comtrade).
- Дисковое пространство: минимальное (приложение — статика, несколько PHP-файлов и
  JSON-справочники). ⚠️ ЗАПОЛНИТЬ фактические значения ОЗУ/CPU тарифа хостинга.

## 2. Начало работы

1. Открыть адрес приложения в браузере.
2. Ввести пароль на форме входа.
3. После авторизации откроется рабочее пространство с меню разделов.

## 3. Эксплуатация по разделам

### 3.1. Данные
Загрузить пользовательскую выгрузку (Excel `.xlsx`/`.xls`) либо выбрать статистику
UN Comtrade (страны, коды ТН ВЭД, периоды). Выбранный источник определяет
доступный набор анализов.

### 3.2. Обработка
Очистка и подготовка данных: работа с заголовками, приведение столбцов,
нормализация таблицы.

### 3.3. Анализ
Просмотр аналитических представлений по товарам, странам и контрагентам. На
агрегированной статистике UN Comtrade анализы контрагентского уровня недоступны —
программа поясняет причину.

### 3.4. Обогащение
Дополнение данных справочниками и пересчёт стоимостных показателей по курсам ЦБ РФ.

### 3.5. Презентация
Сборка отчёта по результатам анализа и экспорт (в т.ч. самодостаточный HTML).
Отчёты по зеркальной статистике содержат обязательную подпись об источнике данных.

### 3.6. Зарубежная таможня
Просмотр открытых зарубежных таможенных данных по импорту:
- переключение страны (Колумбия / Перу);
- сводка: число импортёров, товарных кодов, сумма CIF, объём;
- поиск по названию импортёра и по коду ТН ВЭД / названию товара;
- сортировка таблицы по клику на заголовок; клик по строке раскрывает все товарные
  коды выбранного импортёра;
- «Экспорт в Excel» выгружает текущую выборку.

Отображаются только импортёры-юридические лица; под таблицей указан источник и его
статус.

### 3.7. О программе
Просмотр версии и назначения программы.

### 3.8. Выход
Кнопка выхода завершает сессию.

## 4. Администрирование экземпляра

Отдельной панели администратора в приложении нет — управление выполняется на
уровне сервера правообладателем.

- **Управление доступом:** пароль входа задаётся одноразово через `setup.php` и
  хранится как bcrypt-хеш в `config.php`. Смена пароля — повторная установка
  (пересоздание `config.php`). При использовании Basic Auth уровня сервера —
  управление `.htpasswd`.
- **Прокси к UN Comtrade:** режим работы прокси `comtrade.php` (белый список
  параметров, файловый кэш); ключ API, если задан, хранится вне репозитория.
- **Резервное копирование:** `config.php` и справочники (`data/*.json`,
  `data/foreign/*.json`).
- **Диагностика:** журналы PHP и веб-сервера на площадке размещения.

## 5. Ограничения эксплуатации

- Работа только через HTTPS (cookie сессии помечены `Secure`).
- Доступ к приложению и всей его статике — только после авторизации.
- Загруженные пользователем данные на сервере не сохраняются — обработка ведётся в
  браузере; при закрытии сессии несохранённые результаты теряются.
