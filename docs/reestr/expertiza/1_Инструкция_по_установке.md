# Инструкция по установке экземпляра программного обеспечения, предоставленного для проведения экспертной проверки

**Программное обеспечение:** «Delomant — Аналитика ВЭД»
**Экспертный стенд:** https://delomant-analytics-system.ru/
**Учётные данные для экспертизы:** ⚠️ ЗАПОЛНИТЬ (логин/пароль тестовой учётной записи)

## 1. Общие сведения

«Delomant — Аналитика ВЭД» — веб-приложение (одностраничное приложение, SPA),
работающее в браузере. **Установка на рабочее место пользователя (эксперта) не
требуется** — доступ осуществляется через браузер по адресу экспертного стенда
после авторизации.

Для проведения экспертизы предоставлен развёрнутый и готовый к работе экземпляр
ПО. Экземпляр размещён правообладателем на веб-хостинге; эксперту достаточно
открыть адрес стенда и войти по предоставленным учётным данным (раздел 2).

Раздел 3 приводится для полноты и описывает порядок самостоятельного
развёртывания экземпляра из дистрибутива (если это потребуется экспертизе).

## 2. Доступ к предоставленному экземпляру (основной способ)

1. Открыть в браузере адрес: `https://delomant-analytics-system.ru/`.
2. На форме входа ввести пароль (учётные данные — см. заголовок документа).
3. После авторизации загружается рабочее пространство приложения с меню разделов.

Требования к рабочему месту эксперта:
- современный браузер (Chrome, Yandex Browser, Firefox, Edge — актуальные версии);
- разрешение экрана от 1280×800;
- доступ в интернет.

## 3. Порядок самостоятельного развёртывания экземпляра из дистрибутива

### 3.1. Требования к площадке размещения
- Веб-сервер Apache с поддержкой `.htaccess` (в типовой схеме — за nginx), PHP 8+.
- HTTPS (обязательно — cookie сессии помечены атрибутом `Secure`).
- Исходящий доступ сервера в интернет (для прокси к внешнему API UN Comtrade).

### 3.2. Сборка дистрибутива
В корне проекта выполнить:
```bash
node build.mjs
```
Сборщик формирует каталог `dist/` с приложением: статика упаковывается в
`assets/*.dat`, добавляются PHP-скрипты входа/отдачи/прокси/установки и `.htaccess`.
Токен установки задаётся переменной окружения `SETUP_TOKEN` (если не задан —
генерируется случайный).

### 3.3. Выкладка
Содержимое каталога `dist/` загрузить в корень сайта на хостинге.

### 3.4. Установка паролей входа
Открыть `setup.php` с корректным токеном установки и задать пароль. Скрипт создаёт
`config.php` с bcrypt-хешем пароля и после этого отключается. Пароль в открытом
виде нигде не сохраняется.

Форма установки позволяет задать **два пароля**:
- **Основной пароль** — полный доступ ко всей функциональности, включая загрузку
  пользовательских выгрузок (Excel).
- **Пароль для проверяющих** (необязательный) — ограниченный (экспертный) доступ.
  В этом режиме скрыта загрузка пользовательских выгрузок; доступны обработка,
  анализ, обогащение, презентации и открытые источники (UN Comtrade и World Bank
  WITS). Роль определяется на стороне сервера по введённому
  паролю и хранится в серверной сессии — обойти ограничение на стороне клиента
  нельзя.

Для экспертизы проверяющим передаётся **пароль для проверяющих**.

**Добавление экспертного пароля на уже развёрнутом инстансе.** Так как `setup.php`
отключается после создания `config.php`, на действующем стенде экспертный пароль
добавляется вручную: в файл `config.php` дописывается строка
`$AUTH_HASH_EXPERT = '<bcrypt-хеш>';`. Хеш генерируется командой
`php -r "echo password_hash('ВАШ_ПАРОЛЬ', PASSWORD_BCRYPT);"`.

### 3.5. Проверка развёртывания
Открыть корень сайта — должна отобразиться форма входа; после ввода пароля
загружается приложение.
