# Документация, содержащая описание функциональных характеристик экземпляра программного обеспечения, предоставленного для проведения экспертной проверки

**Программное обеспечение:** «Delomant — Аналитика ВЭД»

## 1. Назначение

«Delomant — Аналитика ВЭД» — веб-приложение для анализа данных
внешнеэкономической деятельности (ВЭД). Предназначено для аналитиков,
специалистов по ВЭД и логистике. Обеспечивает загрузку выгрузок
таможенных/торговых данных, их обработку и очистку, аналитику по контрагентам,
странам и товарам, обогащение справочниками, работу с открытыми зарубежными
таможенными данными и подготовку презентаций-отчётов.

Программа работает как одностраничное веб-приложение (SPA) в браузере; доступ
закрыт авторизацией; установка на компьютер пользователя не требуется.

**Класс ПО по классификатору Минцифры:** ⚠️ ЗАПОЛНИТЬ (ориентировочно —
раздел «Прикладное ПО», классы систем сбора, хранения, обработки, анализа и
визуализации данных / отраслевые информационно-аналитические системы; указать
точный код при подаче).

## 2. Функциональные возможности

Приложение построено из семи функциональных модулей (левое меню).

### 2.1. Данные
Загрузка пользовательских выгрузок в форматах Excel (`.xlsx`, `.xls`) либо
альтернативная загрузка зеркальной статистики **UN Comtrade** по странам, кодам
ТН ВЭД и периодам (через встроенный серверный прокси). Определённый источник
данных влияет на доступный набор анализов.

### 2.2. Обработка данных
Очистка и нормализация загруженной таблицы: работа с заголовками, приведение
столбцов, подготовка данных к анализу. Результат — обработанный набор, на котором
строятся аналитические представления.

### 2.3. Анализ
Аналитические представления по обработанным данным: разрезы по товарам, странам,
контрагентам (отправители, получатели, изготовители), динамике и стоимости.
Анализы, требующие контрагентского уровня, недоступны на агрегированной
статистике UN Comtrade — программа явно объясняет причину вместо построения
пустого графика.

### 2.4. Обогащение данных
Дополнение записей из встроенных справочников (например, справочник компаний) и
пересчёт стоимостных показателей по курсам ЦБ РФ. Предусмотрено расширение
источников обогащения.

### 2.5. Презентация
Формирование презентаций-отчётов в фирменном стиле на основе результатов анализа,
включая экспорт самодостаточного HTML-дека. Отчёты по зеркальной статистике
сопровождаются обязательной подписью об источнике данных.

### 2.6. Зарубежная таможня
Витрина открытых зарубежных таможенных данных по импорту (Колумбия — DIAN,
Перу — SUNAT): поиск по импортёру, коду ТН ВЭД (HS6) и названию товара,
сортировка, разворот импортёра по товарным кодам, экспорт в Excel. Показатели —
объёмы (нетто), стоимость (CIF/FOB), число позиций в разрезе «импортёр × товар».
Названия товаров приводятся на русском по коду ТН ВЭД. Отображаются только
импортёры-юридические лица; данные снабжаются пометкой об источнике и его статусе.

### 2.7. О программе
Сведения о версии и назначении программы.

## 3. Отличительные особенности

- Работа как с собственными выгрузками пользователя, так и с открытой
  международной статистикой (UN Comtrade) через безопасный серверный прокси с
  белым списком параметров.
- Слой открытых зарубежных таможенных данных (Колумбия, Перу) с приведением
  названий товаров на русский по коду ТН ВЭД и фильтрацией персональных данных
  (отображаются только юридические лица).
- Разграничение доступного анализа по типу источника данных.
- Доступ к приложению и всей его статике только после авторизации.
- Не требует установки на рабочее место — работает в браузере.

## 4. Архитектурные характеристики

Клиент-серверная схема с «тонким» серверным слоем. Основная логика (обработка,
анализ, обогащение, формирование отчётов) выполняется в браузере на стороне
клиента; серверная часть на PHP отвечает за авторизацию, отдачу статики и
проксирование внешних API.

- **Клиентский слой:** `index.html` (вёрстка SPA), `scripts/main.js` (прикладная
  логика, ванильный JavaScript без фреймворка), `scripts/foreign_customs.js`
  (модуль «Зарубежная таможня»), `styles/main.css`, библиотека `xlsx` (SheetJS)
  для разбора Excel в браузере, локальные справочники в JSON.
- **Серверный слой (PHP 8):** `index.php` (вход, сессия), `asset.php` (отдача
  статики только авторизованным пользователям), `comtrade.php` (прокси к
  UN Comtrade с белым списком параметров и файловым кэшем), `setup.php`
  (одноразовая установка пароля).
- **Сборка:** `build.mjs` переносит статику в `assets/*.dat` и закрывает её
  выдачей только через `asset.php` по проверке сессии.
- **Офлайн-пайплайн зарубежных данных:** препроцессоры на Python
  (`scripts/parse_*.py`, `scripts/prep_foreign_data.py`) разбирают большие
  открытые выгрузки вне рабочего сервера; в приложение попадают только компактные
  JSON-агрегаты и словарь «код ТН ВЭД → русское название товара».

## 5. Модель безопасности

- Единая авторизация: приложение, статика и прокси закрыты одной PHP-сессией.
- Cookie сессии: `Secure`, `HttpOnly`, `SameSite=Lax`.
- Пароль хранится только как bcrypt-хеш, вне репозитория.
- Прокси к внешнему API не является open-proxy: наружу уходят только
  валидированные параметры из белого списка.
- Данные пользователя (загруженные Excel-выгрузки) на сервере не сохраняются —
  парсинг и анализ выполняются в браузере.

## 6. Технологический стек

- **Клиент:** HTML5, CSS3, JavaScript (ES5/ES6, без фреймворка), библиотека
  `xlsx` (SheetJS Community Edition, Apache-2.0).
- **Сервер:** PHP 8 (`declare(strict_types=1)`), файловые сессии; Apache +
  `.htaccess` за nginx.
- **Инструменты сборки/сопровождения (в дистрибутив не входят):** Node.js
  (`build.mjs`, скрипты сбора справочников — только стандартная библиотека),
  Python 3 (офлайн-препроцессоры зарубежных данных — только стандартная
  библиотека).

Единственная внешняя runtime-зависимость приложения — `xlsx` (Apache-2.0).
Серверная часть написана на стандартном PHP без внешних библиотек. Компонентов с
лицензиями, ограничивающими использование в РФ, нет.
