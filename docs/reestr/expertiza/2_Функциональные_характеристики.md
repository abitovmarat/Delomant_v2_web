# Документация, содержащая описание функциональных характеристик экземпляра программного обеспечения, предоставленного для проведения экспертной проверки

**Программное обеспечение:** «Delomant — Аналитика ВЭД»

**Версия:** 0.9

**Форма предоставления:** развёрнутый веб-стенд с персональной учётной записью
для проведения экспертной проверки

## 1. Назначение

«Delomant — Аналитика ВЭД» — веб-приложение для подготовки аналитических
материалов по внешнеэкономической деятельности. Программа получает открытую
международную торговую статистику UN Comtrade и World Bank WITS, рассчитывает рыночные
показатели, анализирует динамику, географию и товарную структуру торговли,
формирует отчёты и презентации.

Целевые пользователи — аналитики, специалисты по ВЭД, закупкам, логистике и
исследованию рынков. Установка программы на компьютер пользователя не
требуется; работа выполняется в современном веб-браузере после авторизации.

**Класс ПО по классификатору Минцифры:** ⚠️ ЗАПОЛНИТЬ после проверки
действующего классификатора. Предполагаемая группа — системы сбора, обработки,
анализа и визуализации данных либо отраслевые информационно-аналитические
системы.

## 2. Функциональные возможности заявляемой версии 0.9

### 2.1. Получение данных

- получение статистики UN Comtrade по странам, регионам, странам-партнёрам,
  направлению торговли, кодам HS6 и годовым или месячным периодам;
- получение статистики World Bank WITS по странам, партнёрам,
  крупным товарным разделам и годовым периодам;
- получение тарифных ставок WITS TRAINS для оценки условий доступа на рынок;
- поиск товарного кода по русскому наименованию;
- сохранение исходного ответа выбранного открытого источника.

### 2.2. Анализ

Программа строит аналитические представления по доступным измерениям набора:

- объёмы и стоимость по годам и кварталам, темпы роста и CAGR;
- объёмы и средневзвешенные цены по странам;
- динамика цен по годам и кварталам;
- потоки между странами в виде диаграммы Санки;
- сигналы и риски: концентрация, зависимость от лидера и волатильность цен;
- изменения рынка между двумя выбранными периодами;
- настраиваемые сводные таблицы, CAGR, средневзвешенные показатели и
  классификация товаров.

Поддерживаются фильтры по направлению, стране и нескольким товарным кодам.
Если источник не содержит нужного уровня детализации, неприменимые функции
скрываются или выводят объяснение причины.

### 2.3. Отчёты и презентации

- конструктор слайдов с изменением порядка, заголовков и текста;
- мастер автоматической сборки отчёта по доступным данным;
- детерминированные заголовки-выводы и комментарии из рассчитанных показателей;
- независимый товарный срез для аналитических слайдов;
- аналитическая записка в самодостаточном HTML;
- экспорт презентации в PPTX, PDF и HTML;
- экспорт аналитических таблиц в CSV/XLSX и графиков в PNG;
- сводная книга Excel с исходными данными UN Comtrade или World Bank WITS,
  аналитическими листами и
  провенансом источника.

### 2.4. Системные возможности

- авторизация с разделением полного и экспертного доступа;
- общий пароль владельца и персональные учётные записи проверяющих;
- личный кабинет проверяющего;
- панель владельца для создания и удаления экспертных аккаунтов;
- защищённая выдача приложения и его собственной статики;
- суточный файловый кеш запросов UN Comtrade и World Bank WITS.

## 3. Состав функций экспертного стенда

Для проведения экспертной проверки предоставляется персональная учётная
запись. После входа проверяющий видит личный кабинет и переходит из него в
демонстрационный стенд.

На стенде доступны:

- получение открытой торговой статистики UN Comtrade и World Bank WITS;
- получение и отображение тарифных ставок WITS TRAINS;
- анализ полученной открытой статистики;
- формирование аналитических записок и презентаций;
- экспорт результатов;
- сведения о программе.

## 4. Архитектурные характеристики

Программа использует клиент-серверную схему с тонким серверным слоем.

- **Клиент:** `index.html`, `scripts/main.js`, `styles/main.css`, локальные
  JSON-справочники. Интерактивная аналитика и экспорт результатов выполняются
  в браузере.
- **Сервер:** PHP 8; `index.php` отвечает за вход и роли, `asset.php` — за
  защищённую статику, `admin.php` — за аккаунты, `comtrade.php` и `wits.php` — за
  доступ к UN Comtrade и World Bank WITS и кеш, `setup.php` — за первичную
  настройку.
- **Хранение:** базы данных нет; эксплуатационные файлы содержат только
  конфигурацию, bcrypt-хеши аккаунтов, необязательный ключ API и кеш открытых
  источников.
- **Сборка:** `build.mjs` формирует защищённый `dist/`; публикация выполняется
  централизованно по FTPS из GitHub Actions.

## 5. Модель безопасности

- приложение, собственная статика и прокси защищены одной PHP-сессией;
- cookie имеет атрибуты `Secure`, `HttpOnly`, `SameSite=Lax`;
- после входа идентификатор сессии регенерируется;
- пароли хранятся только как bcrypt-хеши;
- панель аккаунтов доступна только владельцу и защищена CSRF-токеном;
- прокси передают внешним API только проверенные параметры из белых списков;
- прямой доступ к конфигурации, внутренней статике и кешу запрещён;
  Basic Auth не используется.

## 6. Технологический стек и зависимости

- **Клиент:** HTML5, CSS3, JavaScript без фреймворка, SVG, Canvas.
- **Сервер:** PHP 8, cURL, SimpleXML, JSON, PHP-сессии; Apache с
  `mod_rewrite` за nginx.
- **Сборка:** Node.js 22 и стандартные модули Node.js.
- **Клиентские библиотеки:** SheetJS CE 0.20.3 (Apache-2.0), JSZip 3.10.1
  (выбран вариант MIT), jsPDF 2.5.1 (MIT), html2canvas 1.4.1 (MIT),
  PptxGenJS 3.12.0 (MIT).

Клиентские библиотеки включены в состав дистрибутива и выдаются с сервера
приложения. UN Comtrade и World Bank WITS вызываются серверными прокси.

## 7. Эксплуатационные ограничения

- требуется HTTPS;
- доступность и полнота открытых данных зависят от API UN Comtrade и World Bank WITS;
- объём одновременно анализируемого набора ограничивается памятью и
  вычислительными ресурсами браузера;
- несохранённые данные теряются после закрытия или обновления страницы.
