рабочее пространство с меню из шести разделов.

## 7. Раздел «Зарубежная таможня»
Просмотр открытых зарубежных таможенных данных по импорту.
- Переключение страны (Колумбия / Перу).
- Сводка: число импортёров, товарных кодов, сумма CIF, объём.
- Поиск по названию импортёра и по коду ТН ВЭД / названию товара.
- Сортировка таблицы по клику на заголовок; клик по строке раскрывает все
  товарные коды выбранного импортёра.
- Кнопка «Экспорт в Excel» выгружает текущую выборку.
- Отображаются только импортёры-юридические лица; под таблицей указан источник и
  его статус.
