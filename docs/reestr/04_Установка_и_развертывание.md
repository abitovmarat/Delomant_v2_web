# Инструкция по установке и развёртыванию

Приложение разворачивается на веб-хостинге с поддержкой PHP. Установка на
рабочие места пользователей не требуется — доступ через браузер.

## Требования к площадке
- Веб-сервер Apache с поддержкой `.htaccess` (за nginx), PHP 8+.
- HTTPS (обязательно — cookie сессии помечены `Secure`).
- Доступ сервера в интернет для прокси к UN Comtrade.

## Порядок развёртывания

1. **Сборка дистрибутива.** В корне проекта выполнить:
   ```bash
   node build.mjs
   ```
   Сборка формирует каталог `dist/` c приложением: статика упакована в
   `assets/*.dat`, добавлены PHP-скрипты входа/отдачи/прокси и `.htaccess`.
   Токен установки задаётся переменной окружения `SETUP_TOKEN` (иначе
   генерируется случайный).

2. **Выкладка.** Содержимое `dist/` загрузить в корень сайта на хостинге.

3. **Установка пароля.** Открыть `setup.php` с корректным токеном установки и
   задать пароль входа. Скрипт создаёт `config.php` с bcrypt-хешем и после этого
   отключается. Пароль в открытом виде нигде не сохраняется.

4. **Проверка.** Открыть корень сайта — должна отображаться форма входа; после
   входа загружается приложение.

## Обновление данных-справочников
Справочники (курсы ЦБ, страны Comtrade) обновляются офлайн-скриптами и
перевыкладываются как статические JSON:
```bash
node scripts/fetch_cbr_rates.js
node scripts/fetch_comtrade_countries.js
```

> ⚠️ ЗАПОЛНИТЬ: конкретный хостинг, домен, способ загрузки файлов (SFTP/панель),
> путь к `.htpasswd`, если используется Basic Auth уровня сервера.
