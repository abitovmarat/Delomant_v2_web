# Состав ПО, технологический стек и компоненты

Документ описывает фактический состав версии 0.9. Исходный код приложения и
сформированный `dist/` различаются расположением файлов: серверные скрипты из
`server/` при сборке переносятся в корень сайта, а клиентская статика — в
защищённый каталог `assets/`.

## 1. Состав программного обеспечения

| Компонент | Файлы исходного кода | Назначение |
|---|---|---|
| Веб-интерфейс SPA | `index.html` | Разметка шести функциональных модулей |
| Клиентская логика | `scripts/main.js` | Загрузка, обработка, анализ, обогащение и экспорт |
| Оформление | `styles/main.css` | Стили интерфейса и материалов экспорта |
| Авторизация и кабинет | `server/index.php` | Вход, PHP-сессия, роли и кабинет эксперта |
| Защищённая статика | `server/asset.php`, `server/htaccess` | Проверка сессии, отдача ассетов, маршрутизация и запреты доступа |
| Администрирование | `server/admin.php`, `server/setup.php` | Первичная настройка и экспертные аккаунты |
| Интеграция UN Comtrade | `server/comtrade.php` | Серверный прокси, валидация и кеширование |
| Интеграция World Bank WITS | `server/wits.php` | Серверный прокси, разбор XML и кеширование |
| Сборщик | `build.mjs` | Формирование защищённого каталога `dist/` |
| Служебные скрипты данных | `scripts/fetch_comtrade_countries.js`, `scripts/sync_wits_country_names.js` | Подготовка и локализация справочников стран |
| Справочные данные | `data/*.json`, `data/Logo.png` | Курсы валют, страны, регионы, коды ТН ВЭД и служебный справочник компаний |

Сформированный дистрибутив содержит PHP-точки входа в корне, приложение в
`app/index.html` и собственную статику в `assets/*.dat`. Каталоги исходного
репозитория `docs/`, `md/`, `.github/`, а также инструменты разработки в
дистрибутив не включаются.

Служебный справочник компаний указан для полноты технического состава. Функции
контрагентского анализа и обогащения, которые могут использовать этот файл, не
входят в заявляемые функциональные характеристики версии 0.9.

## 2. Технологический стек

### 2.1. Клиент

- HTML5 и CSS3;
- JavaScript ES5/ES6 без прикладного фреймворка;
- SVG и Canvas для визуализации и графического экспорта;
- File API браузера для локального чтения пользовательских файлов.

### 2.2. Сервер

- PHP 8 с `declare(strict_types=1)`;
- стандартные PHP-сессии и файловое хранение конфигурации;
- расширения PHP cURL, SimpleXML и JSON;
- Apache с `mod_rewrite` и поддержкой `.htaccess`, размещённый за nginx;
- HTTPS.

### 2.3. Сборка и публикация

- Node.js 22 в GitHub Actions;
- стандартные модули Node.js `fs`, `path`, `crypto`, `zlib`, `https`;
- GitHub Actions;
- `lftp` и FTPS для публикации.

## 4. npm-зависимость и фактический runtime

`package.json` и `package-lock.json` содержат пакет `xlsx` версии 0.18.5. Он не
импортируется `build.mjs` или отслеживаемыми служебными скриптами и не
используется браузером: приложение фактически получает SheetJS 0.20.3 из
официального CDN.

До фиксации заявляемого релиза необходимо выбрать один вариант и привести
репозиторий к нему:

1. удалить неиспользуемую npm-зависимость и документировать CDN-версию; либо
2. закрепить SheetJS 0.20.3 как локальный компонент и включить его в
   защищённую статику дистрибутива.

Для воспроизводимости, автономности и экспертизы предпочтителен второй вариант.
Он также устраняет зависимость запуска приложения от доступности сторонних CDN.

## 5. Системное и внешнее ПО

| Наименование | Роль | Входит в дистрибутив |
|---|---|---|
| Современный веб-браузер | Исполнение клиентской части | Нет |
| PHP 8 и расширения cURL, SimpleXML, JSON | Исполнение серверной части и внешние запросы | Нет |
| Apache/nginx | Публикация веб-приложения | Нет |
| Node.js 22 | Сборка дистрибутива и подготовка справочников | Нет |
| GitHub Actions, `lftp` | Автоматизированная публикация | Нет |

Системное ПО предоставляется средой разработки, CI и хостинг-провайдером.

## 6. Внешние сервисы и источники данных

| Сервис | Способ обращения | Назначение |
|---|---|---|
| UN Comtrade API | Серверный прокси `comtrade.php` | Международная торговая статистика |
| World Bank WITS API | Серверный прокси `wits.php` | Торговая статистика и тарифы TRAINS |
| ЦБ РФ | Офлайн-подготовленный `data/cbr_rates.json` | Курсы валют для пересчётов |
| CDN SheetJS | Прямой HTTPS-запрос браузера | Библиотека XLS/XLSX |
| cdnjs | Прямой HTTPS-запрос браузера | JSZip, jsPDF, html2canvas |
| jsDelivr | Прямой HTTPS-запрос браузера | PptxGenJS |

UN Comtrade, World Bank WITS, ЦБ РФ и CDN не входят в состав программы.

## 7. Материалы по лицензиям к релизу

Перед формированием фиксированной заявляемой версии необходимо:

- сохранить тексты лицензий всех пяти клиентских компонентов в составе
  комплекта поставки;
- добавить файл уведомлений о сторонних компонентах и требуемую атрибуцию
  SheetJS;
- проверить фактически поставляемые файлы и версии по контрольным суммам;
- после решения о локальном размещении библиотек актуализировать таблицу выше.
