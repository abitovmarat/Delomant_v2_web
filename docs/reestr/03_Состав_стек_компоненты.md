# Состав ПО, технологический стек и компоненты

## Состав программного обеспечения

| Компонент | Файлы | Назначение |
|---|---|---|
| Веб-интерфейс (SPA) | `index.html` | Вёрстка приложения, шесть модулей |
| Клиентская логика | `scripts/main.js` | Обработка, анализ, обогащение, презентации |
| Оформление | `styles/main.css` | Стили интерфейса |
| Серверная часть | `server/*.php` | Авторизация, отдача статики, прокси, установка |
| Сборщик | `build.mjs` | Подготовка дистрибутива для хостинга |
| Скрипты сбора данных | `scripts/fetch_*.js` | Офлайн-формирование справочников |
| Справочные данные | `data/*.json`, `data/Logo.png` | Курсы ЦБ, компании, страны, маппинг товаров |

## Технологический стек

### Клиент
- HTML5, CSS3.
- JavaScript (ES5/ES6, «ванильный», без фреймворка).
- Библиотека `xlsx` (SheetJS) — парсинг Excel в браузере.

### Сервер
- PHP 8 (`declare(strict_types=1)`), файловые сессии.
- Apache + `.htaccess` (Basic Auth, rewrite); хостинг за nginx.

### Инструменты сборки и сопровождения
- Node.js — исполнение `build.mjs` и скриптов сбора данных (используют только
  стандартную библиотеку Node: `https`, `fs`, `path`, `crypto`).

### Внешние источники данных (по сети, не входят в состав ПО)
- UN Comtrade API — зеркальная торговая статистика.
- ЦБ РФ — курсы валют (собираются офлайн-скриптом в `cbr_rates.json`).

## Стороннее ПО

| Наименование | Роль | Тип |
|---|---|---|
| PHP | Серверная среда исполнения | Системное ПО хостинга |
| Apache / nginx | Веб-сервер | Системное ПО хостинга |
| Node.js | Сборка и офлайн-сбор данных | Инструмент разработки |

Указанное системное ПО предоставляется хостинг-провайдером и средой разработки,
в дистрибутив программы не включается.

## Open Source-компоненты

| Компонент | Версия | Лицензия | Назначение |
|---|---|---|---|
| xlsx (SheetJS Community Edition) | ^0.18.5 (см. `package.json`) | Apache-2.0 | Разбор Excel-файлов на клиенте |

Иных внешних runtime-зависимостей приложение не имеет (`package.json` содержит
единственную зависимость — `xlsx`). Серверная часть написана на стандартном PHP
без внешних библиотек; скрипты сборки используют только стандартную библиотеку
Node.js.

> ⚠️ ЗАПОЛНИТЬ / ПРОВЕРИТЬ: подтвердить точную версию и текст лицензии `xlsx`
> по `node_modules/xlsx/LICENSE`; при обновлении зависимостей — актуализировать
> таблицу. Приложить копии текстов лицензий, если требуется экспертизой.

## Подтверждение по компонентам

Все использованные Open Source-компоненты распространяются по разрешительным
лицензиям (Apache-2.0), допускающим использование в составе программы, включаемой
в реестр. Компонентов с лицензиями, ограничивающими использование в РФ, нет.
