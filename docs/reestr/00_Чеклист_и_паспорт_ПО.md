# Реестр отечественного ПО — комплект документов

Пакет технической документации для включения ПО **«Delomant — Аналитика ВЭД»** в
единый реестр российских программ (Минцифры). Комплект пополняется по мере
развития программы.

> Легенда статусов: ✅ готово · 🟡 черновик (заполнены технические части, нужны факты правообладателя) · ⬜ заготовка.
