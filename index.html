О программе

Delomant Analytics v2

Веб-приложение для анализа данных внешнеэкономической деятельности (ВЭД). Обработка таможенных деклараций, построение аналитических отчётов и визуализация торговых потоков.

Возможности

  • Обработка данных: Маппинг колонок G##, извлечение дат, обогащение из справочника, нормализация, расчёты цен за кг
  • Анализ: Темп роста, статистика, тренды, сводные таблицы, CAGR, диаграммы Санки, средневзвешенные цены, классификация товаров
  • Визуализация: Линейные, площадные, столбчатые и точечные графики с экспортом в PNG/SVG
  • Отчёты: Формирование отчётов с экспортом в CSV/XLSX

Технологии

Frontend: Vanilla HTML5, CSS3, JavaScript (ES5)
Библиотеки: SheetJS (для работы с XLSX/XLS)
Шрифт: DejaVu Sans
Deployment: GitHub Pages

Поддерживаемые форматы

CSV
XLSX
XLS
