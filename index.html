О программе

Delomant Analytics v2

Веб-приложение для анализа данных внешнеэкономической деятельности (ВЭД). Загрузка и обработка таможенных деклараций, построение аналитических отчётов, визуализация торговых потоков, генерация презентаций и ИИ-исследование товарных рынков.

Обработка данных

  • Загрузка: один или несколько файлов CSV/XLSX/XLS с объединением строк
  • Маппинг колонок: автоматический (G## в русские названия) и пользовательский
  • Извлечение дат: Месяц, Квартал, Год из даты декларации
  • Обогащение из справочника: VLOOKUP-объединение по ключевой колонке
  • Очистка: удаление пробелов, дубликатов, пустых строк, нормализация компаний
  • Нормализация: даты в ISO, числа, коды ТН ВЭД до 10 знаков
  • Расчёты: USD/кг стат., USD/кг факт., руб./кг, курс ЦБ РФ, пользовательское отношение
  • Контроль качества: удаление пустых колонок, фильтрация столбцов

Анализ

  • Объёмы и стоимость: сводные таблицы по годам/кварталам, CAGR, 3 графика с YoY-ростом
  • Объёмы по странам: таблица с долями, горизонтальная диаграмма топ-10
  • Динамика цен по странам: средневзвешенная цена USD/кг, линейный график топ-10 стран
  • Структура импорта: диаграмма Санки Отправитель → Получатель (тонны)
  • Структура по изготовителям: диаграмма Санки Изготовитель → Получатель (тонны)
  • Поквартальная динамика цен: руб./кг и USD/кг по кварталам, линии по годам

Презентация

  • Конструктор слайдов: перетаскивание, редактирование заголовков и текста
  • Типы слайдов: титул, содержание, разделитель, текст, аналитика (6 типов), итоги, контакты
  • Фильтрация по ТН ВЭД: каждый аналитический слайд работает со своим срезом данных
  • Экспорт PPTX: графики из вкладки Анализ вставляются как изображения
  • Экспорт PDF: многостраничный документ с теми же слайдами

ИИ-исследование

  • Чат с данными: задавайте вопросы по загруженным таможенным данным
  • Контекст: сводка, топ стран и динамика по годам передаются в запрос автоматически
  • Генерация слайдов: ИИ формирует аналитические выводы и добавляет их в презентацию
  • API-ключ: используется ваш собственный ключ Claude API, хранится только в браузере

Экспорт

  • Данные: CSV, XLSX (закреплённая шапка, автоширина колонок)
  • Графики анализа: PNG (Retina 2x)
  • Аналитические таблицы: XLSX, CSV
  • Презентация: PPTX (PowerPoint), PDF

Технологии

Frontend: Vanilla HTML5, CSS3, JavaScript (ES5)
Библиотеки: SheetJS (XLSX/XLS), JSZip, PptxGenJS, jsPDF
Курсы валют: ЦБ РФ (предзагрузка 2020–2026 + API-фолбэк)
Шрифт: DejaVu Sans
Deployment: GitHub Pages
